# Breezy site

Public marketing site for the Breezy games studio (static HTML/CSS, no build step).

- `index.html`: studio page
- `tinyhive/`: Tinyhive game page
- `privacy.html`: privacy page (current build)

Open `index.html` in a browser, or serve this folder with any static server. Links are relative, so it works under a sub-path such as /breezy-site/.
